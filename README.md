# VSEPR Lab

Web app didattica interattiva per lo studio di:

- geometria VSEPR;
- visualizzazione 3D delle molecole;
- ibridazione degli orbitali;
- animazione degli orbitali atomici e ibridi;
- orbitali p non ibridati e legami π;
- forme limite e ibridi di risonanza;
- nube π delocalizzata;
- esercizi interattivi per studenti.

## Pubblicazione con GitHub Pages

1. Crea su GitHub un nuovo repository, ad esempio `vsepr-lab`.
2. Carica nella radice del repository tutti i file contenuti in questo pacchetto:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. Apri **Settings → Pages**.
4. In **Build and deployment** scegli:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Premi **Save**.
6. Dopo alcuni minuti GitHub mostrerà l'indirizzo pubblico della web app.

L'indirizzo sarà normalmente nel formato:

`https://NOMEUTENTE.github.io/vsepr-lab/`

## Aggiornare l'app

Per pubblicare una nuova versione è sufficiente sostituire `index.html` nel repository con la nuova versione della web app. GitHub Pages aggiornerà automaticamente il sito.

## Utilizzo

L'app è autonoma: non richiede server, database o installazioni. Funziona direttamente nel browser.

## Nota didattica

Le rappresentazioni di ibridazione `sp³d` e `sp³d²` sono presentate come modello scolastico classico. Per le specie ipervalenti, i modelli quantomeccanici moderni non richiedono una partecipazione significativa degli orbitali d.
